# 버그 작업 문서 목록

이 디렉터리는 버그 리포트, 원인 분석, 수정 계획, 검증 결과를 보관합니다.

## 작성 기준

- 버그별로 하나의 문서를 만듭니다.
- 재현 절차, 기대 동작, 실제 동작, 영향 범위를 먼저 기록합니다.
- 원인 분석과 수정 계획은 확인한 사실과 추정을 구분합니다.
- 수정 후 회귀 테스트와 검증 결과를 기록합니다.
- 장기 규칙으로 남길 내용은 관련 영구 문서로 승격합니다.

## 파일명 기준

작업 문서가 많아지면 연도별 디렉터리를 만들고 번호를 붙입니다.

```text
2026/001-example-bug.md
```

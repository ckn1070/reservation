# Spike 작업 문서 목록

이 디렉터리는 기술 가능성 확인, 대안 비교, 제한 시간 내 실험 결과를 보관합니다.

## 작성 기준

- 확인할 질문과 실험 범위를 먼저 정합니다.
- 실험은 결정을 돕는 데 필요한 만큼만 수행합니다.
- 실험 결과, 결론, 폐기할 내용, 남길 지식을 구분합니다.
- 채택한 결정은 관련 영구 문서로 승격합니다.

## 파일명 기준

작업 문서가 많아지면 연도별 디렉터리를 만들고 번호를 붙입니다.

```text

```

# 작업 문서 템플릿 목록

이 디렉터리는 작업 산출물 작성에 사용할 기본 템플릿을 보관합니다.

## 현재 템플릿

- [feature-template.md](feature-template.md): 신규 기능 작업 문서 템플릿입니다.
- [bug-template.md](bug-template.md): 버그 작업 문서 템플릿입니다.
- [improvement-template.md](improvement-template.md): 개선 작업 문서 템플릿입니다.
- [spike-template.md](spike-template.md): spike 작업 문서 템플릿입니다.

## 사용 기준

- 템플릿은 그대로 복사해 작업 문서를 시작합니다.
- 필요 없는 섹션은 삭제할 수 있지만 배경, 목표, 범위, 검증 결과, 영구 문서 승격 여부는 가능한 한 남깁니다.
- 작업이 끝나면 결과와 후속 작업을 반드시 정리합니다.

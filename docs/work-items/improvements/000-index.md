# 개선 작업 문서 목록

이 디렉터리는 기존 기능 보완, 성능 개선, 구조 개선 작업 문서를 보관합니다.

## 작성 기준

- 개선 주제별로 하나의 문서를 만듭니다.
- 현재 문제, 목표, 대안, 선택안, 검증 계획을 기록합니다.
- 구조, 성능, 운영 안정성에 영향이 있으면 설계 워크플로우를 적용합니다.
- 확정된 지식은 관련 영구 문서로 승격합니다.

## 파일명 기준

작업 문서가 많아지면 연도별 디렉터리를 만들고 번호를 붙입니다.

```text
2026/001-example-improvement.md
```

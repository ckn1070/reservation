# 기능 작업 문서 목록

이 디렉터리는 신규 기능 작업 문서를 보관합니다.

## 작성 기준

- 기능별로 하나의 문서를 만듭니다.
- 기능 배경, 목표, 범위, 제외 범위, 수용 기준, 설계 메모, 개발 계획, 검증 결과를 기록합니다.
- 확정된 제품 범위는 `product` 문서로 승격합니다.
- 확정된 도메인 규칙은 `domain` 문서로 승격합니다.
- 확정된 API 계약은 `api` 문서로 승격합니다.
- 확정된 DB 구조는 `database` 문서로 승격합니다.
- 확정된 구조 결정은 `project` 또는 `architecture` 문서로 승격합니다.

## 파일명 기준

작업 문서가 많아지면 연도별 디렉터리를 만들고 번호를 붙입니다.

```text
2026/001-example-feature.md
```
